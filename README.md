# Diageo plc DCF valuation

This portfolio submission demonstrates an integrated five-year FCFF valuation for Diageo plc.

## Live case study

The project is presented online at:

https://diageo-dcf-finance-portfolio.shawna-mascarenhas20.chatgpt.site

The site is currently private and can be reviewed before any public sharing decision.

## Files

- `Diageo_DCF_Portfolio.xlsx` - complete model, assumptions, forecasts, WACC, terminal value, sensitivity analysis, equity bridge, sources and checks.
- `Diageo_DCF_Valuation_Memo.pdf` - concise explanation of the investment conclusion, methodology, risks and principal assumptions.
- `Diageo_DCF_Valuation_Presentation.pptx` - seven-slide presentation with editable forecast, FCFF, equity-bridge and sensitivity charts.
- `Diageo_DCF_Interview_Guide.docx` - model walkthrough, technical questions, assumption defenses and preparation checklist.
- `APPLICATION_MATERIALS.md` - CV bullets, personal-statement copy, portfolio descriptions and submission guidance.
- `MODEL_AUDIT_REPORT.md` - reconciliation results, valuation review, limitations and pre-submission refresh list.
- `SUBMISSION_CHECKLIST.md` - final refresh, native-application, upload and interview checks.
- `CHECKSUMS.sha256` - file-integrity hashes for the principal portfolio artifacts.
- `PORTFOLIO_CASE_STUDY.md` - public-facing project narrative for GitHub, Notion or a portfolio website.

## Headline conclusion

The base-case DCF produces an implied value of GBP 22.65 per diluted share versus a GBP 15.93 reference price, representing 42.2% implied upside. The result uses a 7.32% WACC, 2.50% terminal growth rate and mid-year discounting.

## Suggested review sequence

1. Review the presentation for the high-level thesis.
2. Read the valuation memo.
3. Open `Model Guide` and `Investment Summary` in the workbook.
4. Review `DCF Assumptions`, operating cases and FCFF.
5. Review WACC, terminal-value cross-checks and sensitivity.
6. Finish with `Equity Bridge`, `Checks` and `DCF Sources`.

## Important note

This is an academic portfolio exercise and is not investment advice. Material judgment areas include terminal assumptions, EABL proceeds, book-value treatments for associates and NCI, pension taxation and GBP/USD translation.
